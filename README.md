# 소방설비 허브

소방시설 설계자와 건물 관계자를 위한 무료 소방설비 계산기 — GitHub Pages용 정적 싱글 페이지 사이트입니다.

**라이브 사이트:** https://firepump.github.io/

## 소개

한국어 소방설비 계산기 허브입니다. 소방시설법과 화재안전기준(NFSC), 일반적인 소방 실무 기준에 따라 만들었습니다. 순수 HTML5, CSS3, 바닐라 JavaScript만 사용했습니다. 프레임워크, 빌드 단계, 백엔드가 없습니다.

## 계산기 (모두 클라이언트 측에서 동작)

1. **스프링클러 헤드 수** — 방호 면적과 헤드 1개당 방호 면적으로 필요 헤드 수와 최대 간격 계산.
2. **소화기 소요량** — 바닥 면적과 건물 용도별 방호 면적으로 필요 소화기 개수와 배치 기준 계산.
3. **소화전 수압** — 설치 높이, 호스 길이, 노즐 조건으로 필요 수압(kPa/bar)과 필요 양정 계산.
4. **감지기 배치 간격** — 천장 높이와 감지기 종류(연기/열)에 따른 방호 면적, 필요 개수, 배치 간격 계산.
5. **피난 시간 산정** — 재실 인원, 출구 폭, 이동 거리, 층수로 출구 통과 시간과 총 피난 시간 계산, 3분 목표 판정.

또한 건축물 용도별 소방시설 설치 기준 요약표, 6개의 실무 소방 가이드, 자주 묻는 질문, 소개와 면책 조항을 포함합니다.

## GitHub Pages 배포 방법

1. GitHub 사용자 **motorwindinghub** 아래에 **fire-hub**라는 이름의 공개 저장소를 만듭니다.
2. 이 폴더의 모든 파일(`index.html`, `README.md`, `.nojekyll`, `favicon.svg`, `guides/`)을 저장소 루트에 업로드합니다.
3. 저장소에서 **Settings → Pages → Build and deployment → Deploy from a branch → 브랜치 `main`, 폴더 `/ (root)` → Save**를 선택합니다.
4. 몇 분 안에 **https://firepump.github.io/** 주소로 사이트가 열립니다.

## 로컬 미리보기

```bash
python3 -m http.server 8000
# http://localhost:8000/ 접속
```

## 면책 조항

모든 계산 결과는 참고용 추정치입니다. 소방시설 설계와 설치는 관련 법령과 화재안전기준(NFSC)이 우선하며, 반드시 소방시설 설계업체와 소방시설관리사의 검토를 받아야 합니다.
